# Expense Manager App

## 📱 Description
A premium, **offline-first** personal finance tracking application built using **Flutter**. It provides a seamless experience for managing daily expenses with instant UI responsiveness and background cloud synchronization.

## 🚀 Key Features
- **Offline-First Architecture**: View and manage data without an internet connection using local SQLite storage.
- **Bi-directional Cloud Sync**: Automatically synchronizes local changes with a remote REST API once online.
- **Intelligent Deletion**: Implements a "Lazy-Deletion" strategy to maintain data consistency across multi-device sessions.
- **Advanced State Management**: Powered by **BLoC** for a fully reactive and scalable architecture.
- **Personalized Experience**:
    - Customizable monthly budget limits with real-time alert UI.
    - Persistent Daily Reminder system with a custom time picker.
    - Device-bound nickname personalization.
- **Premium UI/UX**: Professional dark-themed interface featuring glassmorphism, shimmers, and a custom floating navigation bar.

## 🛠 Tech Stack
- **Framework**: [Flutter](https://flutter.dev) (Dart)
- **State Management**: [flutter_bloc](https://pub.dev/packages/flutter_bloc)
- **Local Database**: [sqflite](https://pub.dev/packages/sqflite)
- **Networking**: [http](https://pub.dev/packages/http)
- **Architecture**: Repository Pattern + BLoC
- **Storage**: SharedPreferences (for user settings)

## 🏗️ Getting Started
1. Clone the repository.
2. Run `flutter pub get` to install dependencies.
3. Use `flutter run` to launch the application.
